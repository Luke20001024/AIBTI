# AIBTI 建筑师风格化探索：首轮评审

日期：2026-08-26
范围：离线图片探索，不接入线上页面。

## 结论

这套 V3 二维几何角色语言可以迁移到真实建筑师，并且不必牺牲人物辨识度。首轮最值得继续的是“克制的角色演出型”：保留真人面部、年龄和姿态锚点，但让动作、道具与一处极简建筑符号承担职业叙事。

推荐基线是 `zaha-v2`。它比单纯的资料肖像更能进入 AIBTI 的人物宇宙，又没有像人格角色那样把情绪推到戏剧化极端。`zaha-v1` 适合作为科普资料区的肖像型备选；`mies-v1` 证明同一语法能覆盖明显不同的年龄、性别表达和人物气质。

## 三张图的共同优点

- 真人身份不是靠皮肤纹理、皱纹、发丝和摄影光线维持，而是靠头型、眼距、鼻颌、发型轮廓、神态与姿态；
- 角色与建筑处于同一个二维切纸世界，建筑没有退回写实渲染；
- 人物轮廓、头部和关键手势在 6:5 画幅中安全，缩小后仍有识别层级；
- 没有加入文字、Logo、商业角色特征、额外人物或戏仿元素；
- Zaha 的两版保持同一人物身份，但形成了“资料肖像型 / 角色演出型”的明确对照。

## 尚需警惕

- 建筑师图需要比人格角色多保留一些面部结构，因此更容易滑向“矢量化照片”；后续仍需控制眼睛、鼻翼、唇线和面部小阴影数量；
- 不同建筑师不能被强行套成同一动作换脸。统一的是抽象层级、材质、轮廓和构图纪律，不是姿势；
- 经典照片中的道具只能作为资料锚点使用。雪茄、眼镜、帽子等不能变成夸张笑点或营销符号；
- 搭档人物必须真实呈现共同署名，不能因为单人图更容易生成，就把 Wang Shu × Lu Wenyu 拆成默认主角与附属人物；
- 当前建筑师照片及本轮生成图只处于原型研究状态。任何公开或商业使用前，仍需完成原图来源、摄影署名、版权、肖像语境和替换策略复核。

## 建议的后续生产顺序

1. 先决定以 `zaha-v2` 的角色型为唯一主方向，还是保留“角色型用于结果故事、肖像型用于资料卡”的双层系统；
2. 图片服务恢复后优先补做 `wang-lu-v1`，先验证最难的双人平权边界；
3. 再做 Ando 与 Gaudí：分别验证极简克制与高装饰倾向，防止建筑背景重新变复杂；
4. 只有四类边界均通过，才扩展至全部首发建筑师；
5. 全量生成前先做 390px 资料卡和结果页的离线构图模拟，仍不直接改线上引用。
