# VOID V3 · 手机版静态编辑长页规划

> 状态：执行基线
>
> 适用范围：仅限 `/preview/void-v2/`
>
> 强约束：不修改原版 `/result/void/`，不复用原版组件，不把关键内容藏在点击、切换、拖动或折叠之后

## 1 核心目标

把 VOID 从一套需要操作才能读完的交互 Demo，改成一份自然滚动即可完整阅读的建筑人格杂志

这次不减少知识深度，而是删除交互外壳，将原版展开卡片里的高价值内容直接进入主阅读路径

核心结果：

- 人格主体继续占据首屏视觉中心
- 主叙事交互从约 16 个收敛为 0
- 三种空间反应、三种风格、建筑师故事和三座作品全部默认可见
- 每座作品恢复原版的 hook、三个观察点和完整故事
- 结尾仅保留保存与分享两个功能动作
- 所有可见编辑文案去掉句末句号
- 手机版每次滑动获得一个明确观点，不出现标签页、滑块、展开层或箭头催促

## 2 内容策略

### 2.1 三层信息结构

每个核心内容单元统一为三层：

1. 一句可被记住、截图或转发的判断
2. 三个具体的空间观察点
3. 一段解释机制、人物冲突或身体经验的故事

### 2.2 原版素材继承

直接吸收但重新编辑以下素材：

- VOID 的外在印象、隐藏感受、信息过载反应与建筑逻辑
- 安藤忠雄的拳击经历、非科班背景、自学路径以及对距离与身体移动的敏感
- 光之教堂的斜墙入口、十字光、明暗变化与身体路线
- 水御堂的莲花池、向下动线、朱红空间以及寺方反对方案的冲突故事
- 地中美术馆的地下体量、几何庭院、明暗校准与岛屿地景关系
- 沃思堡现代艺术博物馆与 21_21 DESIGN SIGHT 作为继续探索的延伸作品
- 原版六张建筑细节图作为第二观察角度

### 2.3 文案规则

- 可见文案不使用句末 `。` 或英文句点
- 短句优先通过换行建立节奏
- 删除“点击、拖动、查看、展开、进入”等操作提示
- 删除“你懂了之后再看下一层”的教学口吻
- 每个观点只解释一次
- 保留逗号、顿号、冒号、破折号与问号等有实际语义的标点
- 系统提示同样去掉句末句号

## 3 页面结构

### 01 人格封面

保留现有强人物构图、超大 VOID、寂静的边界、人格钩子、关键词和风格

删除“进入 VOID”和向下箭头

首屏主视觉以 `concepts/C01-persona-cover.png` 及用户于 2026-08-28 确认的同版截图作为构图锁

人物约束：

- 人物是首屏人格锚点，但不能成为覆盖全屏的单一海报主体
- 390px 宽度下人物视觉宽度控制在约 68% 至 74% 视口，不超过 330px
- 人物头顶大约位于主视觉高度 36% 至 40% 处
- 面部不可超过视口宽度约 34%，避免人物压缩建筑空间
- 十字光、左侧厚墙与右侧纵向 VOID 至少共同占据约 40% 的有效视觉面积
- 人物右侧必须保留连续的竖向光缝与混凝土边界
- 360px 与 390×700 短屏可以降低人物宽度，但不能裁切脸部或让背景建筑消失
- 后续人格章节不再重复同等级的大人物构图，以建筑与文字为主

首屏允许文案：

- VOID
- 寂静的边界
- 你不是喜欢空
- 你是在用空，把噪音筛出去
- 克制 / 厚度 / 仪式感
- 现代主义 × 极简主义倾向 × 批判性地域主义

### 02 VOID 人格切面

将原版四条人格素材编辑成三个静态切面和一句建筑判断：

- 别人看到的你
- 你没有说出口的
- 信息过载时
- 你的建筑逻辑

版式使用编号、开放留白和一张放大人物局部，不做卡片切换

### 03 光 / 边界 / 路径

三种空间反应全部连续呈现

每项包含：

- 大字标题
- 一句人格判断
- 一句空间解释
- 关键词
- 一张对应空间图

删除状态标签、拖动条、动态叠层和操作提示

### 04 风格剖面与反误读

同一章节内静态呈现三层风格公式：

- 现代主义给 VOID 骨架
- 极简主义倾向给 VOID 纪律
- 批判性地域主义让 VOID 保留温度

随后接一个紧凑的反误读段：

- 你追求有重量的安静
- 你拒绝为了空而空
- VOID 的危险是把克制误认成高级

三层风格全部默认可见，不保留标签切换

### 05 安藤忠雄作为证据

肖像、姓名和故事一次显示完整

核心叙事：

- 从拳击台走进建筑史的自学者
- 没有读过建筑学院，通过阅读、旅行与亲自走进建筑完成自学
- 拳击带来的距离、节奏和身体移动意识，最终进入厚墙、光与绕行路径
- 与 VOID 的关系不是清水混凝土，而是切、绕、藏三种空间动作

删除“展开人物故事”和切 / 绕 / 藏跳转栏

### 06 三个动作，三座建筑

三座作品改为连续的静态编辑章节，每座约占 1.5 至 2 个手机视口

每座作品结构：

1. 动作大字与作品身份
2. 主图
3. 一句作品 hook
4. 到现场看三个细节
5. 一段完整故事
6. 一张细节图或第二角度

作品顺序：

- 切 / 光之教堂
- 绕 / 水御堂
- 藏 / 地中美术馆

删除作品标签、路线箭头、展开细节与折叠层

### 07 同一种静默，不止一种方法

路易斯·康与彼得·卒姆托保留为两条静态谱系，不与安藤忠雄争夺主角位置

章节底部增加“继续看两座建筑”：

- 沃思堡现代艺术博物馆
- 21_21 DESIGN SIGHT

推荐作品只保留图片、名称、一个观察句和三个关键词

### 08 最终判词与分享

保留人物海报与最终判词

只保留两个主功能动作：

- 保存 VOID 人格封面
- 分享 VOID

重新测试与方法来源作为无箭头的普通页脚链接

## 4 视觉系统

### 4.1 方向

继续使用建筑文化杂志与实验时装画册的交叉语言

- 黑、骨白、混凝土灰和低饱和蓝
- 超大窄体英文与克制中文黑体
- 直角、细线、开放版式，不新增圆角卡片系统
- 图片作为证据，不作为按钮背景
- 章节之间通过色块、图像比例与文字密度变化建立节奏
- 编号只承担阅读定位，不表现为可点击控件

### 4.3 概念参考锁

- `concepts/C01-persona-cover.png`：首屏主视觉与人物比例的最高优先级参考
- `concepts/C08-static-personality-and-instincts.png`：仅参考静态分带和信息同时可见，不采纳其中过大的人物比例或误生成的操作文案
- `concepts/C09-static-style-and-ando.png`：风格三层同时展开、反误读带与安藤故事的版式参考
- 新生成的作品静态章节概念：三层信息结构与主图 / 细节图节奏参考

概念图中的错误文字、句末句号、菜单、箭头或操作提示都不属于可见文案锁

### 4.2 手机版规则

- 设计基准宽度 390px
- 兼容 360px 与短屏 390×700
- 页面不出现横向滚动
- 正文建议 16 至 18px，行高 1.65 至 1.8
- 观察点至少 15px，不使用微小脚注代替主要信息
- 作品主图稳定为 4:3 或 3:4，细节图可为 16:10
- 每个章节至少有一个明显的视觉焦点，但不重复同一张卡片公式

## 5 交互预算

- 轮播

结尾允许：

- 分享 VOID
- 重新测试文字链接
- 方法与来源文字链接
