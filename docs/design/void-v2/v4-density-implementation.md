# VOID V4 · 手机高密度改造锁定

> 视觉方向沿用已确认的 C01、C09、C10
>
> 实施依据为 390 × 844 真实浏览器截图与 2026-08-28 密度审计
>
> 本轮不新增美术方向、不新增探索交互、不修改正式 `/result/void/`

## 1. 成功指标

- 页面总高从 19,051px 收敛到 11,816–13,504px，即约 14–16 个 844px 手机屏
- 核心可见正文从约 2,153 字提高到 2,500–2,800 字
- 除首屏与纯图片转场外，普通内容屏目标为 140–180 个有效汉字
- 章节入口不超过 0.45 屏
- 非首屏主图原则上不超过 44vh
- 每滚动一屏至少获得一个新判断、一个证据，以及一个反例或可应用方法

## 2. 版式系统

- 页面宽度：390px 母版，内容实际宽度扣除浏览器滚动条后约 377px
- 页面边距：18–20px
- 章节上下间距：32–48px
- 章节标题：40–46px，禁止再次使用首屏级 56–84px 巨字
- 单元标题：24–32px
- 正文：15–17px，行高 1.55–1.68
- 标签：11–13px，蓝色只用于编号、判断名和关键动作
- 继续使用无圆角、细分隔线、黑 / 骨白 / VOID 蓝、Barlow Condensed 与中文黑体
- 首屏继续作为唯一海报式大视觉，后续不再重复整屏人物

## 3. 内容结构

### 首屏

首屏以一张 780 × 1564 栅格海报完整呈现，不再由 HTML 叠字、背景与人物图共同渲染

排版比例回到已确认 Demo：左上人格编号、中部中文判断、右侧竖排 VOID、人物受控于中下部、风格谱系收在底部

四行人格护照移到首屏后的第一个内容模块：第一反应、空间偏好、隐藏风险、风格来源

### 空间反应

每个单元固定为：先看什么、成立条件、伪 VOID、关键词与一张受控高度图片

### 风格与建筑师

压缩过渡标题，保留三层风格与“切 / 绕 / 藏”；肖像、身份与故事在一屏半内完成

### 三座作品

每座固定为：主图、身份、核心判断、现场路径、关键事实、可以借走什么、两张紧凑细节图

### 谱系

康与卒姆托不再使用两张 610px 高的大卡，改为安藤 / 康 / 卒姆托四维比较表；推荐部分使用真实建筑照片作为证据

### 延伸作品与结尾

两座延伸作品改为紧凑索引；结尾海报缩短，只保留判断、保存与分享

## 4. 禁止项

- 不增加 tab、slider、details、summary、点击展开或箭头指引
- 不恢复“进入 VOID”
- 不使用句末全角句号
- 不增加伪百分比、人格分数或没有依据的排行
- 不用缩小到难读的字体换取密度
- 不用 AI 生成图冒充建筑师的具体建成作品
