# VOID V5 · 参考版对比与收敛实施计划

> 参考对象：`http://localhost:3001/preview/void-device.html`
>
> 当前对象：`http://127.0.0.1:3000/preview/void-v2-device.html`
>
> 约束：390 × 844 手机优先，首屏保持不变，不增加内容型交互，不修改正式 `/result/void/`

## 1. 对比结论

| 维度 | 参考版 | 当前 V4 | V5 目标 |
| --- | ---: | ---: | ---: |
| 页面总高 | 3,275px | 12,593px | 5,500–6,500px |
| 手机屏数 | 3.9 屏 | 14.9 屏 | 6.5–7.7 屏 |
| 有效可见文字 | 645 字 | 2,507 字 | 1,500–1,850 字 |
| 平均文字密度 | 约 166 字 / 屏 | 约 168 字 / 屏 | 约 210–250 字 / 屏 |
| 页面图片 | 7 张 | 19 张 | 10 张 |
| 首屏后标题 | 24–30px | 38–45px 居多 | 26–32px |
| 单座作品高度 | 约 472px | 1,246–1,349px | 560–680px |

关键判断：当前版的问题不是字少，而是内容被太多 UI 层级、重复标题和重复图片拉长

参考版最值得借鉴的不是具体样式，而是它让每个章节只承担一件事：一个判断、一段说明、一张证据图，然后立即进入下一个内容节点

## 2. 保留与删除

### 必须保留

- 已确认的完整单图首屏
- VOID 对光、边界、路径的判断方式
- “把克制误认成高级”的反转
- 安藤忠雄从拳击、自学到身体路径感的故事
- 光之教堂、水御堂、地中美术馆三座作品
- 康与卒姆托的真实建筑证据
- 沃思堡与 21_21 DESIGN SIGHT 两座延伸作品
- 结尾保存、分享与来源入口

### 合并或删除

- 删除三张反应氛围图，光 / 边界 / 路径改为三行判断
- 人格切面、反应、阴影面、风格来源合并为一个连续的“空间倾向”章节
- 三层风格不再各自形成大段面板，只保留轴测图与三条方法解释
- 建筑师章节不再用大动作字和独立故事区，改为肖像旁的一段紧凑人物叙事
- 每座作品删除两张细节图库，只保留一张主图
- “现场路径 / 空间发生了什么 / 为什么重要 / 关键事实 / 可以借走”五层 UI 合并为：核心判断、三步空间路径、一个可借走的方法
- 删除四列表格，改为安藤 / 康 / 卒姆托三条横向方法对照
- 结尾不重复风格长句，只保留最终判断和动作

## 3. V5 页面结构

### 01 首屏 · 约 782px

保持当前单图完全不变

### 02 你的空间倾向 · 约 1,050–1,250px

- 一句人格总判断
- 四项人格护照压缩为两列数据行
- 光 / 边界 / 路径三行，每行只保留“你先看什么”和“伪 VOID”
- 小型轴测图与现代主义 / 极简倾向 / 地域校正三条解释并排组织
- 以“克制不是高级，改变经验才成立”收口

### 03 代表建筑师 · 约 420–520px

- 左侧姓名、身份、切 / 绕 / 藏
- 右侧 134 × 167px 肖像
- 一段 70–100 字人物故事

### 04 三座作品 · 约 1,900–2,250px

每座作品固定为：

- 220–244px 主图
- 作品名、英文名与年代
- 一句核心判断
- 01 / 02 / 03 三步空间路径
- 一句“可以借走”的方法

不使用图库、不使用背景切换、不使用额外卡片

### 05 方法谱系 · 约 850–1,000px

- 三行方法对照：安藤切开空间、康建立秩序、卒姆托生成气氛
- 金贝尔与瓦尔斯温泉两张真实建筑照片并列
- 沃思堡与 21_21 DESIGN SIGHT 两张小图并列

### 06 结尾 · 约 380–480px

- 最终人格判断
- 保存、分享
- 重新测试与来源

## 4. 视觉规则

- 首屏后最大标题不超过 32px
- 正文 14–15px，行高 1.52–1.62
- 注释和元数据 10–12px
- 章节上下留白 28–36px
- 正文块内部间距 12–20px
- 主图统一 220–244px，不允许自然比例把作品拉成长屏
- 只使用细线、编号与 VOID 蓝建立层级
- 不使用深色大面板、半透明叠卡、巨型动作字或装饰性图标
- 同一信息只允许出现一次视觉强调

## 5. 模块实施顺序

1. 新建 V5 紧凑内容结构，复用现有事实，不重新发明叙事方向
2. 合并 personality、reactions、shadow、styles 为一个静态 editorial digest
3. 收敛建筑师组件
4. 重写作品组件并移除 6 张细节图库的页面渲染
5. 将谱系比较表改为三条方法对照和两组双列真实图片
6. 压缩结尾
7. 更新内容合同和手机端 E2E 合同

## 6. 验收条件

- 390 × 844 页面总高位于 5,500–6,500px
- 有效可见文字位于 1,500–1,850 字
- 图片总数为 10，全部加载成功
- 无水平溢出
- 无 tab、details、summary、range 与内容展开按钮
- 仅结尾保留保存和分享按钮
- 首屏截图与 V4 完全一致
- 单座作品总高不超过 720px，并能在一个 844px 屏内看到主图、判断与至少两条路径
- 康与卒姆托继续使用真实建筑照片
- 所有可见内容无句末句号
