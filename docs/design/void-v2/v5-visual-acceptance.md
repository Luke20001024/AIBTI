## 1. 对比结果

| 指标 | 参考版 | V4 | V5 |

V5 没有复制参考版的内容薄度，而是复制它的编辑纪律：一个判断、一段解释、一张证据图，之后立即进入下一个内容节点

## 2. 模块验收

### 首屏

- V4 单图首屏保持不变
- 仍为唯一海报式大视觉
- 页面只渲染一张完整首屏图，不恢复 HTML 叠字

### 空间倾向

- personality、reactions、shadow、styles 四段合并为一个 1,078px 编辑章节
- 光 / 边界 / 路径取消三张氛围图，改为三行判断与失效反例
- 四项人格护照改为两列数据行
- 轴测图缩为 126 × 174px，只负责解释结构、体量和场地三层关系

### 建筑师

- 总高 407px
- 肖像固定为 134 × 167px
- 姓名、身份、切 / 绕 / 藏与人物故事在同一章节内完成

### 三座作品

- 章节总高 2,159px
- 光之教堂 664px，水御堂 702px，地中美术馆 683px
- 每座只保留一张 244px 主图
- 六张重复细节图库退出主页面
- 固定结构为作品身份、核心判断、三步路径、故事与可以借走的方法

### 方法谱系

- 四列表格改为安藤、康、卒姆托三条开放方法行
- 金贝尔艺术博物馆与瓦尔斯温泉继续使用真实建筑照片
- 沃思堡与 21_21 DESIGN SIGHT 使用两列紧凑索引

### 结尾

- 总高 461px
- 保存与分享并列排列
- 保留最终判断、重新测试与来源入口
