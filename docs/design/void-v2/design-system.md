# VOID V2 · Design System

> 状态：G1 设计系统冻结
>
> 目标：移动端建筑编辑长页，而不是通用结果卡或 SaaS 界面

## 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| --void-bone | #F1EEE5 | 主背景、开放文字区 |
| --void-ink | #0B0F16 | 深色章节、主文字、主按钮 |
| --void-concrete | #77736C | 次级文字、材质边界 |
| --void-light | #FFFDF5 | 深色背景主文字、硬光 |
| --void-blue | #1D4E85 | 当前状态、关键词、细线、VOID 信号 |
| --void-muted | #6C6A65 | 英文信息、来源、辅助文字 |

背景颜色锁定为 Warm Bone，不允许改成纯白、奶油黄或暖灰替代。深色章节锁定为 Ink Black。图片不添加色洗或整图透明覆盖。

## 字体

- VOID、动作字、英文屏级信号：Barlow Condensed，700–800；
- 中文主标题：系统黑体链，800–900，紧凑字距；
- 中文正文：系统无衬线，400–500；
- 英文项目信息：Barlow Condensed 或系统无衬线，500；
- 控件文字必须显式定义字号、字重、行高，不依赖浏览器默认值。

建议移动端尺度：

| 角色 | 尺度 |
| --- | --- |
| VOID 字标 | clamp(6rem, 30vw, 8.25rem) |
| 人格标题 | clamp(2.8rem, 12vw, 3.5rem) |
| 屏级标题 | clamp(2.1rem, 9vw, 2.75rem) |
| 光 / 界 / 路、切 / 绕 / 藏 | clamp(5rem, 24vw, 7rem) |
| 核心判断 | 1.5–1.875rem |
| 正文 | 1.0625–1.125rem |
| 辅助标签 | 0.8125–0.875rem |

## 间距与容器

- 手机基准宽度：390px；
- 内容 gutter：20px；360px 下可缩至 16px；430px 下不超过 24px；
- 基础间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96；
- 阅读正文最大行宽：26 个中文字符左右；
- 页面不使用全局圆角；图片、按钮、分区边界均为直角；
- 章节主要使用全幅媒体、开放文字区、材料层和深浅背景带；
- 只允许 1px 细线、真实结构阴影和图片自身光影，不使用装饰性 box-shadow。

## 组件家族

1. VoidHero：首屏人物、建筑背景、超大 VOID、锁定文案和风格构成；
2. ReactionSwitcher：光 / 边界 / 路径状态，同一容器，不做轮播卡；
3. VoidShadow：深色人物与反误读开放列表；
4. StyleAnatomy：三层结构与展开说明，不做圆角 Accordion；
5. ArchitectProof：安藤肖像、反标签句、切绕藏动作导航；
6. WorkActions：三种作品状态，共享导航但各有独立图像与排版；
7. LineageBands：康与卒姆托两条开放材料带；
8. ShareEnding：同一人物海报、主次操作和来源入口。

## 图标清单

只允许：

- 向下箭头：进入 VOID；
- 右上箭头：人物故事、空间细节、来源；
- 状态路径线：路径与水御堂动作演示；
- 分享/保存动作在需要系统图标时使用同一 1.5–2px 直线风格。

箭头使用代码原生 SVG，viewBox、stroke、cap 和光学尺寸统一。不使用文本字形代替方向图标。

## 动效

- 首屏：背景硬光 500–700ms 显现；VOID 字标 350–500ms；人物保持稳定，不漂浮；
- 状态切换：220–320ms，图片淡入与文字位移不超过 12px；
- 风格层展开：360–440ms；
- 尊重 prefers-reduced-motion，关闭位移和连续路径动画；
- 不增加视差滚动、持续发光、鼠标跟随或抢夺阅读的循环动画。

## 响应式

- 360、390、430px 是必须实际验证的三档；
- 390×700 短屏允许首屏标题压缩与下方内容延后，但人物脸部、VOID、人格标题和核心判断必须保留；
- 768px 以上仍维持编辑长页，不转换为多列卡片墙；
- 桌面最大内容宽度建议 1180px，人物与图像可放大，但不改变章节顺序；
- 触控目标最小 44×44px；选中状态同时使用位置、下划线或字重，不能只靠蓝色。
