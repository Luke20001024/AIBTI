## 1. 安藤忠雄

- `1941—`：Benesse 与 MoMA 均记录 1941 年生；
- 拳击经历与自学路径：Pritzker Prize 官方 biography 记录其短暂拳击经历及其后自我教育；
- 页面“从拳击台走进建筑史的自学者”是对官方传记的营销压缩，不是直接引语；
- “不是因为清水混凝土”是内容反差句，不否认混凝土的重要性；后文用光、墙与行进序列补足其空间方法。
