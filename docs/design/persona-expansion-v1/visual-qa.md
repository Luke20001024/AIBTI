# ArcBTI 八人格首屏视觉验收记录

## 验收结论

本轮七张新增首屏概念全部通过概念阶段视觉验收，可以作为八人格扩展的视觉方向基准

它们延续了 VOID 已确认的核心方法：一张完整竖版主视觉、人物作为人格主体、建筑作为空间证据、文字直接写进画面，同时避免把七张图做成只换颜色的同一模板

## 验收范围与方法

- 基准图：现有 VOID 首屏 `780 × 1564`
- 新增图：GRID、ROOT、MASS、TECH、FLOW、ORNA、HAND，均为 `887 × 1774`
- 画幅：全部约为 `1:2`，符合竖版手机首屏方向
- 手机归一预览：全部缩放为 `390 × 780`，不裁切，用于检查真实手机尺寸下的文字层级、人物占比和建筑留白
- 总览：按 GRID、ROOT、MASS、VOID、TECH、FLOW、ORNA、HAND 排列，检查家族感与人格辨识度
- 本轮没有接入路由或制作后续页面，因此不进行浏览器交互验收；验收对象是独立的扁平化首屏图

## 逐张结论

### GRID / 一毫米的秩序

- 丁字尺、红色校准方块与巴塞罗那馆共同表达“看见误差就想归位”
- 人物姿态克制但不呆板，建筑水平线强化秩序感
- 蓝、绿大理石与一点红色形成理性中的记忆点
- 结论：通过

### ROOT / 地形的回声

- 苔石被人物捧在手里，瀑布与悬挑平台把“房子从地形里长出来”变成可见动作
- 环境信息量是七张中较高的一张，但人物仍然是第一落点
- 绿色只服务于地形和气候，没有把画面做成泛自然宣传图
- 结论：通过

### MASS / 重量的温度

- 抱臂的封闭姿态对应嘴硬，怀中的小红花补上“关心藏在结构里”的反差
- 巨型住宅体量提供公共性和集体生活的证据
- 灰黑底色与小面积红色让人格钩子成立
- 结论：通过

### TECH / 系统的浪漫

- 手持爆炸结构模型，把技术兴趣转成可阅读的实体道具
- 外露桁架和楼层组件信息较密，但密度与“先看建筑怎么运行”的主题一致
- 使用青蓝色而非荧光赛博风，保留建筑专业感
- 结论：通过

### FLOW / 直线失效以后

- 跨步姿态、连续白壳与斜向构图共同制造速度
- 紫色轨迹只作路径提示，没有依赖光效制造廉价未来感
- 人物和建筑都在运动，是七张里动作张力最明确的一张
- 结论：通过

### ORNA / 万物都想上场

- 陶瓷龙、骨状阳台与手工色块形成“每个细节都有戏份”的完整叙事
- 色彩最丰富，但大面积奶油色留白压住了喧闹
- 人物仍然比背景更醒目，没有退化成建筑旅游海报
- 结论：通过

### HAND / 材料记得一切

- 旧砖瓦、嫩芽和倾斜材料墙把时间、再生与手工放在同一动作里
- 赤褐色、土灰与深蓝形成最稳重的材料叙事
- 人物体量受控，墙体仍留有足够空间感和重量
- 结论：通过
