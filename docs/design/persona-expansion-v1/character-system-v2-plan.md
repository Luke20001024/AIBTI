# ArcBTI 八人格角色系统 V2 改造计划

## 1. 本轮要解决的问题

八张首屏的建筑主题和版式已经成立，但人物系统仍有两个明显问题

第一，当前七张新增图全部被阅读成男性角色，整组结果卡缺少性别与气质层次

第二，除 GRID 外，多数角色的眼睛、鼻子、嘴唇、表情和皮肤明暗过于完整，人物更接近具象动画肖像，削弱了 ArcBTI 应有的建筑模型感和人格原型感

本轮不改内容结构和建筑主题，只校正角色分布与面部视觉语言

## 2. 女性角色替换结论

### FLOW 改为女性角色

FLOW 的代表建筑师是扎哈·哈迪德，女性角色能让首屏和后续内容之间形成自然呼应，同时避免八人格默认以男性作为空间创造者

角色不做温顺或纤弱表达。她仍然保持跨步、越界和高速运动，只把轮廓处理得更轻、更流动：短发或向后切开的几何发片、较长的四肢、锐利但不写实的侧脸

关键词：`锋利 / 流动 / 自主`

### HAND 改为女性角色

HAND 的代表人物是王澍 × 陆文宇，现有男性单人形象会继续放大单一男性作者叙事。改为女性角色，可以更自然地把陆文宇和共同作者关系带进后续内容，也能给八人格补入一个温和、稳定、带材料触觉的人物

角色不做“柔弱的手工女孩”。她仍然像真正参与建造的人：工作服、稳定重心、手持旧砖瓦，表情平静，力量来自身体与材料的接触

关键词：`温和 / 扎实 / 有经验`

## 3. 为什么暂时不替换另外四个角色

- ROOT 已经承担温和、场地和共生，如果同时把 ROOT 与 HAND 都女性化，容易把女性再次绑定到自然、照料和柔软
- MASS 的“强硬外表里藏着关心”依赖当前男性气质形成反差，保留更有内容张力
- TECH 保留男性，但会去掉卡通式笑容和具象五官；后续如需第三位女性，TECH 是优先替换候选，可以主动打破技术人格的男性默认
- ORNA 保留偏男性或中性化角色，让丰富、装饰和戏剧感不被简单等同于女性化

最终分布不是用性别对应性格，而是让女性同时占据动态创造与材料实践两种不同位置

## 4. 面部多边形抽象规范

GRID 作为本轮面部基准，VOID 已经达到接近要求，两张均不重新生成

### 必须满足

- 一张脸由约 6—10 个主要明暗切面构成
- 额头、颧骨、鼻梁、下颌分别形成清楚的大平面
- 眼睛只保留窄形暗面或极简几何形，不画虹膜高光、睫毛和眼袋
- 鼻子以一条折面和一个阴影面表达，不画完整鼻翼与鼻孔
- 嘴部使用一到两条折线或色面，不出现牙齿、唇纹和写实唇部高光
- 不出现毛孔、皮肤纹理、腮红、胡茬和摄影式渐变
- 表情依靠头部角度、眉线和身体动作表达，不依赖完整五官
- 发型由大块几何发片组成，不画细碎发丝
- 阴影边界偏硬，减少圆润的三维人偶感

### 立即淘汰

- 像真人照片经过低多边形滤镜
- 大眼睛、完整眼白、明显瞳孔高光
- 卡通式露齿笑
- 细腻鼻翼、嘴唇或皮肤明暗
- 女性角色依赖睫毛、口红、长发来证明性别
- 面部抽象后人物失去情绪和姿态

## 5. 六张 V2 的具体调整

### ROOT V2

- 保留男性角色、手捧苔石、瀑布、悬挑平台、绿色工作服和全部文字
- 将面部压缩为安静的大切面，眼睛变成窄形暗面，嘴部只保留短折线
- 温和来自微微抬头和双手托住材料，不靠写实微笑

### MASS V2

- 保留男性角色、抱臂、小红花、集体住宅巨构和全部文字
- 加宽下颌与眉骨切面，眼睛缩成深色几何缝隙
- 删除鼻翼、嘴唇和皮肤渐变，让“嘴硬”由姿态完成

### TECH V2

- 保留男性角色、爆炸结构模型、外露桁架、青绿色衬衫和全部文字
- 删除露齿笑与卡通眼睛，改为专注看模型的几何侧脸
- 让手、模型和结构继续承担技术兴趣，面部不抢戏

### FLOW V2

- 替换为女性角色，保留跨步动作、卷轴、紫色路径、连续白壳和全部文字
- 使用短发或后掠几何发片，面部锐利、抽象，不使用睫毛、口红或写实五官
- 身体仍是全组最有速度的一张，女性身份不能削弱力量感

### ORNA V2

- 保留偏男性或中性角色、陶瓷龙、骨状阳台、橙青配色和全部文字
- 将微笑和眼睛压缩成几何线面，取消具象肖像感
- 通过服装色块、手势和陶瓷龙表达戏剧性，不靠五官表演

### HAND V2

- 替换为女性角色，保留旧砖瓦、嫩芽、材料墙、深蓝工作服和全部文字
- 采用短发或束起的块面发型，脸部平静、抽象、有劳动经验感
- 不添加裙装、首饰、妆容或柔焦，柔和来自目光方向、抱持动作和材料触觉

## 6. 生成方式与不变量

模式采用内置图像编辑，每张单独生成

每次使用两张参考图：

1. 对应人格 V1，作为编辑目标，锁定全部版式、文字、建筑、配色、人物占比和道具
2. GRID V1，作为脸部抽象程度参考，只参考多边形面部语言，不复制角色、服装或建筑

必须保持不变：

- 画面比例约 `1:2`
- 所有中文与英文文案逐字不变
- 文案位置、字号层级和底部风格谱系不变
- 人物高度约为画面 `58%—66%`
- 人物宽度不超过画面约 `68%`
- 建筑空间和原有道具不变
- 原有主色与人格识别色不变

## 8. 验收顺序

1. 先看性别是否通过姿态与整体轮廓自然成立，不依赖符号化妆容
2. 再看脸是否达到 GRID 级别的抽象，而非低多边形真人肖像
3. 检查文字是否逐字准确、没有移动或重排
4. 检查人物和建筑面积是否保持
5. 统一缩放为 `390 × 780`，检查手机尺寸下人物辨识度
6. 与 V1 及八人格总览对比，只有明显提升的版本才进入 V2 索引
