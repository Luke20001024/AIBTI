# ArcBTI 八人格结果卡扩展规划 V1

状态：首屏概念设计与后续详情页内容规划

基准版本：VOID V2 当前验收版

本轮范围：

- 保留现有 VOID 页面与资产，不覆盖、不改写
- 为八个人格建立统一但不重复的结果卡叙事系统
- 为 GRID、ROOT、MASS、TECH、FLOW、ORNA、HAND 生成七张首屏完整海报
- VOID 直接使用已通过视觉验收的 `void-hero-poster-v4.png`
- 除首屏概念图外，其余七个人格详情内容本轮只规划，不进入页面实现

## 1. 产品目标

八张结果卡必须同时完成四件事：

1. 用户在三秒内看懂自己属于哪一种建筑人格
2. 人格主体拥有足够张力，同时让建筑空间承担叙事，不退化为人物立绘
3. 首屏可以单独截图传播，脱离测试上下文后仍然成立
4. 首屏向后续内容提出一个明确问题，让用户愿意继续看建筑师、作品和同频谱系

结果页不负责证明用户“懂建筑”，而是把一种原本模糊的空间偏好说得准确、好记、值得转发

## 2. VOID 已验证的首屏母版

### 2.1 固定结构

原生画布以 `780 × 1564` 为目标，约等于 `1:2` 的移动端长海报

首屏信息顺序固定为：

1. 英文人格代码
2. 中文人格标题
3. 两句人话判断
4. 三个短关键词
5. 人格主体与建筑母题
6. 底部建筑风格谱系

整张图作为一个完整 raster poster 进入首屏，不再用 HTML 文本叠加人物图，避免跨设备字体、裁切和层叠漂移

### 2.2 固定视觉语法

- 首屏只允许一个人格主体
- 人物占画面高度约 58%—66%，从中段进入下半屏
- 建筑必须占据约 35%—45% 的可读空间，不能只剩模糊背景
- 文案集中在画面上方约 32%—36%，人物头部不得压住核心句
- 英文代码可以出现两次：一次作为正常标题，一次作为放大的建筑化字形
- 人物采用成熟、几何分面、低多边形编辑插画语言
- 建筑材料可读，但不能变成抢人物的建筑可视化或照片拼贴
- 不使用按钮、箭头、滑动提示、假 UI、徽章和装饰性标签
- 关键词使用人格强调色，其他文字以近黑或骨白为主
- 底部谱系只出现一行，不加入解释

### 2.3 八图必须一致的品牌信号

- 同一类无衬线中文标题与窄体英文代码
- 相近的字号层级和上下安全区
- 相近的几何人物抽象度
- 统一的低频纸张或材料纹理
- 不同人格使用不同构图力线，不能把 VOID 换色复刻七次
- 不直接生成真实建筑作品照片，首屏建筑只承担人格化、概念化的空间母题
- 后续作品章节才使用带来源索引的真实建筑照片

## 3. 共用详情页叙事骨架

七个新结果页未来沿用 VOID 已验证的四段式结构，但每一段都要回答一个不同问题

### 01 / 先说人话

目标：在一屏内把人格从“风格标签”翻译成真实空间行为

内容：

- 一句直白结论
- 一句用户在生活中会做出的具体判断
- 一段建筑史翻译
- 一句防误读提醒，避免把人格降级为表面审美

### 02 / 代表建筑师

目标：用一个具传播力、但有事实基础的入口介绍建筑师

外层只保留：

- 有网感的建筑师标题
- 建筑师姓名、英文名与年代
- 一段约 60—90 字的人物简介
- 一张肖像
- 一个“打开人物故事”入口

详情 Sheet 再展开：经历、方法、争议、合作署名与人格关系

### 03 / 三次实锤

目标：不背理论，用三座作品证明这种空间倾向怎样发生

外层每座作品只保留：真实主图、作品名、年代、地点、一句判断和一个打开入口

详情 Sheet 再放：

- 两张按原比例展示的真实建筑照片
- “现场看什么”三条观察
- 一段作品故事
- 一条事实或建造逻辑
- 一条“可以带走的判断”
- 图片与资料来源入口

### 04 / 同频建筑师

目标：告诉用户人格是一套可继续探索的方法，不等于一位建筑师

外层只显示两位同频建筑师的代表作短幅图、姓名、方法句和一段关系解释

更多生平、作品和差异放入 Sheet

### 结尾 / 可分享判断

目标：形成一句用户愿意保存或发给朋友的结果判断

保留保存人格封面、分享、重新测试与来源页入口

## 5. 各人格详细规划

## GRID / 一毫米的秩序

### 人格命题

GRID 最敏感的不是“整齐”，而是每个结构动作有没有理由。它追求的是可以被读懂的关系：柱网、比例、边界、接缝和留白共同工作

### 首屏文案锁

- Code：`GRID`
- 标题：`一毫米的秩序`
- 判断 1：`你会先看见哪里没对齐`
- 判断 2：`世界一归位，你才开始放心`
- 关键词：`比例 / 接缝 / 结构脑`
- 底部谱系：`现代主义 × 国际主义 × 理性秩序`

### 首屏视觉

- 人物：纵长棱角脸，冷静审视，一手竖握超长丁字尺，一手捏住红色小方块
- 建筑母题：巴塞罗那馆的薄屋顶、细柱、石墙和浅水池，构成清晰的水平与垂直网格
- 构图力线：垂直丁字尺对抗水平屋顶，人物略偏左，右侧保留被放大的竖向 `GRID`
- 色彩：骨白、炭黑、钴蓝、灰绿石材，一处警示红
- 画面情绪：安静、精密、略带挑剔，不做冷冰冰实验室

### 后续叙事

- 先说人话：你不排斥美，你排斥没有理由的美
- 建筑师入口：`建筑界最会把动作删到只剩骨架的人`
- 人物故事重点：巴塞罗那馆被拆除又重建；Lilly Reich 的合作贡献必须明确出现
- 三次实锤：巴塞罗那馆证明自由边界，范斯沃斯住宅证明极限透明，西格拉姆大厦证明主动留出城市空间
- 同频差异：Reich 让材料与展示更敏锐，Johnson 让国际主义进入美国公司与城市语境
- 分享判断：`你要的秩序，从来不是排队，而是每个动作都站得住`

### 风险

- 不把 GRID 写成强迫症段子合集
- 不使用密集蓝图、坐标数字、伪工程 UI
- 建筑不能被网格线完全盖住

## ROOT / 地形的回声

### 人格命题

ROOT 会先感受风、水、地形和生活路线，再决定建筑应当出现在哪里。它的温和来自倾听，固执来自对场所的保护

### 首屏文案锁

- Code：`ROOT`
- 标题：`地形的回声`
- 判断 1：`你会先听风、水和地面怎么说`
- 判断 2：`房子长对地方，比长得漂亮更重要`
- 关键词：`地形 / 气候 / 共生`
- 底部谱系：`有机建筑 × 草原学派 × 场所精神`

### 首屏视觉

- 人物：宽而柔和的脸，双手托一块带少量苔藓的岩石，姿态稳定、温暖但不柔弱
- 建筑母题：流水别墅的水平悬挑、石质核心与一道穿过画面的水流
- 构图力线：人物从左下向上生长，建筑平台从右侧延伸，水流形成纵向连接
- 色彩：森林绿、岩灰、暖棕、米白、少量水蓝与锈红
- 画面情绪：湿润、安定、有呼吸感，拒绝童话森林和旅游海报

### 后续叙事

- 先说人话：你做决定前需要先在现场走一圈
- 建筑师入口：`最会和地形谈判，也最不肯让房子只当观景台的人`
- 人物故事重点：流水别墅把生活放在瀑布上方，让声音和岩石进入日常
- 三次实锤：流水别墅证明建筑与水共生，罗比住宅证明水平线如何塑造生活，西塔里埃森证明建筑可以持续拆、搭、改
- 同频差异：Aalto 更关注材料与人的温度，Fay Jones 把有机建筑压缩进更轻的结构与林地礼拜空间
- 分享判断：`你相信好建筑先向场地低头，再慢慢长出自己的样子`

### 风险

- 不把 ROOT 做成“亲自然”生活方式广告
- 不堆逐片树叶与写实瀑布
- 必须保留人物与建筑之间的结构关系

## MASS / 重量的温度

### 人格命题

MASS 的强体量不是为了显得凶，而是为了托住更多人的共同生活。它把情绪压进结构，把关心藏进公共厨房、屋顶和街道

### 首屏文案锁

- Code：`MASS`
- 标题：`重量的温度`
- 判断 1：`你把关心做成承重结构`
- 判断 2：`嘴上不说，公共屋顶都替人留好了`
- 关键词：`体量 / 诚实 / 集体`
- 底部谱系：`现代主义 × 粗野主义源流 × 集体住宅`

### 首屏视觉

- 人物：方下颌、宽肩、抱臂站立，手肘内侧保护一盆只有一朵红花的小植物
- 建筑母题：马赛公寓的巨大架空柱、模块阳台和厚重水平体块
- 构图力线：低视点、水平重压，人物像一根承重构件，红花成为唯一柔软焦点
- 色彩：混凝土灰、深蓝、炭黑、褪红、骨白
- 画面情绪：有重量但不阴沉，像一张嘴硬却可靠的人格封面

### 后续叙事

- 先说人话：你表达关心的方式，是先把系统安排好
- 建筑师入口：`最想把一栋楼直接做成一座城市的人`
- 人物故事重点：马赛公寓与 Atelier Le Corbusier、André Wogenscky、ATBAT 的合作；同时保留其城市思想的争议
- 三次实锤：马赛公寓证明垂直城市，拉图雷特证明粗粝材料也能精确处理精神空间，昌迪加尔证明制度如何被放大为空间舞台
- 同频差异：史密森夫妇更直接讨论街道与集体结构，Lina Bo Bardi 把粗粝结构变成开放公共生活
- 分享判断：`你的温柔不靠软装，它藏在谁能使用、谁能相遇、谁被照顾到`

### 风险

- 不为粗野主义洗白，也不把争议删掉
- 不把人物做成超级英雄
- 混凝土纹理低频，不能比红花和表情更抢眼

## VOID / 寂静的边界

### 人格命题

VOID 通过删减重新分配注意力，让光、路线、材料和停留成为空间的主角

### 首屏文案锁

- Code：`VOID`
- 标题：`寂静的边界`
- 判断 1：`你不是喜欢空`
- 判断 2：`你是在用空，把噪音筛出去`
- 关键词：`克制 / 厚度 / 仪式感`
- 底部谱系：`现代主义 × 极简主义倾向 × 批判性地域主义`

### 首屏视觉

- 保留当前已通过验收的完整海报
- 人物、十字光、混凝土墙和文字位置不再调整
- VOID 是八图家族的比例、人物张力与信息层级基准，不是所有人格的构图模板

### 后续叙事

当前 V2 已落地，可作为其他七页的内容密度与 Sheet 交互标准

## TECH / 系统的浪漫

### 人格命题

TECH 喜欢能被看懂、维护和继续升级的系统。技术在这里不是冷酷外壳，而是一种对未来仍然有效的乐观

### 首屏文案锁

- Code：`TECH`
- 标题：`系统的浪漫`
- 判断 1：`你看建筑，先看它怎么运行`
- 判断 2：`结构敢露出来，升级路线也得留出来`
- 关键词：`系统 / 装配 / 可升级`
- 底部谱系：`高技派 × 结构表现 × 环境技术`

### 首屏视觉

- 人物：紧凑三角脸、眉眼兴奋，一手托住五层以内的爆炸结构模型，一手调节节点
- 建筑母题：香港汇丰总行式外露桁架、斜撑和中庭空隙
- 构图力线：斜撑穿过画面，结构模型悬在人物胸前，巨大的 `TECH` 像设备编号嵌入背景
- 色彩：银灰、青蓝、深墨色、骨白，一处荧光绿小节点
- 画面情绪：开放、清晰、乐观，拒绝赛博朋克和全息屏幕

### 后续叙事

- 先说人话：你看到东西的第一反应是它怎么运行、坏了怎么修、下一版怎么升级
- 建筑师入口：`建筑界最爱把机房和结构直接端上桌的人`
- 人物故事重点：香港汇丰总行的模块化、公共地面与风水调整，解释系统理性如何与具体语境合作
- 三次实锤：汇丰总行证明建筑像可装配机器，德国国会大厦证明技术可以服务公共透明，赫斯特大厦证明斜网结构可以同时节省材料与制造城市表情
- 同频差异：Rogers 更强调设备与城市开放性，Piano 更擅长让技术变轻、变安静
- 分享判断：`你相信最酷的系统，是大家看得懂、修得了、还能继续长`

### 风险

- 不把 TECH 做成程序员、工程师职业测评
- 不使用全息 HUD、代码雨、霓虹城市和螺栓海
- 结构必须清楚，但人物仍是视觉主体

## FLOW / 直线失效以后

### 人格命题

FLOW 对速度、连续曲面和突破稳定边界的空间变化最敏感。流动必须改变路线、结构和视线，不能停在造型层面

### 首屏文案锁

- Code：`FLOW`
- 标题：`直线失效以后`
- 判断 1：`你不接受空间原地站好`
- 判断 2：`地面、墙和屋顶最好一起起跑`
- 关键词：`速度 / 连续 / 越界`
- 底部谱系：`解构主义 × 新未来主义 × 流动空间`

### 首屏视觉

- 人物：锐利楔形脸，表情兴奋但成熟，身体本身形成一条斜向曲线，一手握卷图，一手画出非发光运动路径
- 建筑母题：盖达尔中心式从地面连续翻起的白色壳体与一个深色切口
- 构图力线：强对角线、前后穿插、人物迈步进入画面，巨大 `FLOW` 随壳体方向转折
- 色彩：深紫、骨白、黑、亮橙，少量电蓝
- 画面情绪：高速、明快、正在发生，不使用魔法光带、雾和炫技粒子

### 后续叙事

- 先说人话：限制在你眼里更像弹射器
- 建筑师入口：`最会把直线开除出项目组的人`
- 人物故事重点：从难以建造的绘画与竞赛图，到数字工具、工程团队和真实建造共同落地
- 三次实锤：盖达尔中心证明表皮连续，MAXXI 证明路线可以像城市道路交叠，大兴机场证明巨大流动必须让方向仍可理解
- 同频差异：Gehry 更强调碎裂与材料碰撞，蓝天组更强调激烈构造与城市事件
- 分享判断：`你要的自由不是乱跑，是让空间拥有下一秒`

### 风险

- 不把 FLOW 做成单纯的曲线审美
- 不使用光效、能量轨迹与超能力姿势
- 动态不能造成文字难读或人物肢体变形

## ORNA / 万物都想上场

### 人格命题

ORNA 相信色彩、工艺、自然形态和故事可以共同构成建筑。丰富必须从结构与建造中长出来，不是把装饰贴满表面

### 首屏文案锁

- Code：`ORNA`
- 标题：`万物都想上场`
- 判断 1：`你相信日常值得认真演一场`
- 判断 2：`结构、色彩和故事，都该有自己的戏份`
- 关键词：`戏剧 / 手工 / 想象`
- 底部谱系：`加泰罗尼亚现代主义 × 新艺术 × 总体艺术`

### 首屏视觉

- 人物：宽颧或心形脸，带舞台感的半鞠躬姿态，掌上托一只小型陶瓷龙，服装只保留一处碎瓷纹样
- 建筑母题：巴特罗之家的骨状阳台、曲窗和少量龙鳞屋顶
- 构图力线：曲面建筑从两侧包围人物，人物位于中央偏下，巨大 `ORNA` 被处理成少量彩色建筑块面
- 色彩：珊瑚红、孔雀蓝、金黄、骨白、深墨色
- 画面情绪：迷人、自得、有幽默感，不做狂欢节海报或儿童乐园

### 后续叙事

- 先说人话：你相信“多一点”也可以非常有纪律
- 建筑师入口：`把石头、骨头和龙都拉进建筑群聊的人`
- 人物故事重点：桂尔公园从失败住宅开发变成公共乐园，结构、工艺和城市生活一起被看见
- 三次实锤：巴特罗之家证明住宅改造可以成为城市神话角色，圣家堂证明结构、光与信仰共同生长，桂尔公园证明碎瓷、地形与公共空间可以合成总体艺术
- 同频差异：Domènech i Montaner 更强调结构理性与工艺整合，Jujol 更擅长用材料拼贴和色彩把日常变成奇异细节
- 分享判断：`你不怕丰富，你只怕每个细节彼此不认识`

### 风险

- 不把 ORNA 写成单纯“喜欢花哨”
- 不生成完整写实立面和密集马赛克
- 陶瓷龙必须是小型道具，不能变成第二主体

## HAND / 材料记得一切

### 人格命题

HAND 从材料来源、手工痕迹和地方时间判断建筑是否真实。旧材料进入新生活，才算真正延续记忆

### 首屏文案锁

- Code：`HAND`
- 标题：`材料记得一切`
- 判断 1：`你会先问这块砖从哪里来`
- 判断 2：`旧材料一开口，城市就有了记忆`
- 关键词：`材料 / 手工 / 时间`
- 底部谱系：`批判性地域主义 × 材料再生 × 在地建造`

### 首屏视觉

- 人物：成熟、温厚、沉静，怀抱旧砖与瓦片，其中一块砖缝长出一枚很小的嫩芽
- 建筑母题：宁波历史博物馆式倾斜大墙、深开口和三条回收材料带
- 构图力线：斜墙从右上压入，人物在左下稳稳托住材料，巨大 `HAND` 像压印在墙内的旧字模
- 色彩：砖褐、瓦灰、靛蓝、苔绿小点、骨白、近黑
- 画面情绪：有时间重量但不怀旧，不出现废墟滤镜和乡村宣传画

### 后续叙事

- 先说人话：你留住旧东西，是因为它们还能继续工作
- 建筑师入口：`最会从拆迁废墟里捡回一座城市的人`
- 人物故事重点：王澍与陆文宇共同创办“业余建筑工作室”，必须避免单一男性作者叙事
- 三次实锤：宁波历史博物馆证明回收材料可以进入公共建筑，象山校区证明校园可用院落与廊桥组织日常，文村改造证明更新可以继续说旧材料和窄巷的语言
- 同频差异：Hassan Fathy 更强调地方工法、气候与社区建造，Anna Heringer 更强调天然材料、教育与共同劳动
- 分享判断：`你相信材料有前半生，设计要负责它的下一段`

### 风险

- 不把 HAND 做成怀旧、古镇或手作消费品牌
- 不逐砖逐瓦写实生成
- 必须明确王澍与陆文宇的共同作者关系

## 6. 首屏视觉生成约束

### 必须满足

- 七张新图均为独立生成，不从 VOID 海报直接换色
- 使用 VOID 海报作为信息结构与比例参考
- 使用各人格现有 V3 角色图作为动作、脸型和建筑母题参考
- 所有人物为虚构成人，不复制真实建筑师面孔
- 人物头、手和关键道具完整
- 建筑空间清楚占有画面，人物不超过画面宽度约 68%
- 文案必须逐字正确，禁止生成替代中文、乱码和伪字
- 海报不出现站点 Header、按钮、箭头、页码、Logo、水印和额外说明
- 画面在 `390 × 782` 缩放后仍能读出标题、两句判断和关键词

### 立即淘汰

- 人物小于画面高度 52%
- 建筑只剩虚化贴图或被人物完全挡住
- 八张共用同一张脸与姿势
- 文字有一处错误
- 出现多人物、额外手臂、错误道具或重复道具
- 变成建筑摄影、PBR 建筑可视化、赛博朋克或儿童卡通
- 用光效、渐变和装饰填满所有空白

## 7. 后续落地顺序

首屏概念通过后再进入页面实现，顺序建议为：

1. GRID：验证最理性的版式边界
2. FLOW：验证最高动态构图边界
3. ROOT：验证最温暖、最自然的空间边界
4. MASS：验证重体量与人物反差
5. TECH：验证复杂结构如何保持清晰
6. ORNA：验证高色彩与高细节仍能克制
7. HAND：验证材料感与在地叙事不落入怀旧

每个人格单独完成：内容锁定 → 首屏实现 → 真实手机截图 → 视觉比对 → 详情内容 → Sheet → 来源索引 → 回归测试

不建议同时复制七套 VOID 页面再填内容，那会把结构错误批量放大
