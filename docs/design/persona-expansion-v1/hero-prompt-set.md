# ArcBTI 七张新增首屏图像提示词集

生成模式：内置图像生成

任务类型：`ads-marketing`

意图：根据 VOID 结果卡和各人格原有角色图生成新的完整移动端人格海报

## 共用提示词

```text
生成一张完整、扁平化输出的 ArcBTI 移动端人格结果海报

参考图 1 是已经通过验收的 VOID 海报，只继承以下内容：约 1:2 的超长移动端比例、上方文字区、下方人格主体、人物与建筑共存、成熟几何分面人物、建筑材料有分量、英文人格代码可以作为建筑化大字进入背景

参考图 2 是该人格已有的角色场景，只继承人格动作、脸型节奏、核心道具、代表建筑母题和主色，不复制原有横向排版

目标画布约 780 × 1564。上方约 34% 保留清晰文字区；一位虚构成人进入下方约 58%—66%；建筑保持约 35%—45% 的可读空间。人物与建筑属于同一个几何编辑插画世界，材质可读但不变成摄影或 PBR 建筑效果图

可见文字必须逐字使用每个人格的文案锁。英文代码出现两次，一次正常横排，一次作为建筑化大字进入右侧空间。除锁定文字外，不加入站点 Header、Logo、按钮、箭头、页码、说明、水印或其他文字

中文使用清晰、粗细有层级的现代无衬线；英文代码使用粗重窄体；关键词使用人格强调色；底部谱系使用骨白文字进入较暗区域

必须只有一位成人，头、手、关键道具完整。人物突出但不能遮完建筑。保持低频纹理、清晰外轮廓和手机缩放后的可读性
```
## GRID 变量

```text
标题：一毫米的秩序
判断：你会先看见哪里没对齐 / 世界一归位，你才开始放心
关键词：比例 / 接缝 / 结构脑
谱系：现代主义 × 国际主义 × 理性秩序
人物：纵长棱角脸、单边抬眉、钴蓝眼镜、超长丁字尺、红色小方块
建筑：巴塞罗那馆式薄屋顶、细柱、灰绿石墙、浅水池
构图：垂直丁字尺对抗水平屋顶
色彩：骨白、炭黑、钴蓝、灰绿、一处警示红
避免：蓝图 UI、坐标数字、实验室、密集网格覆盖
```

## ROOT 变量

```text
标题：地形的回声
判断：你会先听风、水和地面怎么说 / 房子长对地方，比长得漂亮更重要
关键词：地形 / 气候 / 共生
谱系：有机建筑 × 草原学派 × 场所精神
人物：宽而柔和的脸、双手托苔石、温暖但固执
建筑：流水别墅式悬挑平台、石质核心、一道纵向水流
构图：人物从左下生长，建筑从右侧伸出，水串联上下
色彩：森林绿、岩灰、暖棕、米白、少量水蓝
避免：生活方式广告、童话森林、逐片树叶、写实瀑布
```

## MASS 变量

```text
标题：重量的温度
判断：你把关心做成承重结构 / 嘴上不说，公共屋顶都替人留好了
关键词：体量 / 诚实 / 集体
谱系：现代主义 × 粗野主义源流 × 集体住宅
人物：方下颌、宽肩、抱臂、保护一盆单朵红花
建筑：马赛公寓式巨柱、厚水平板、深阳台和屋顶公共空间
构图：低视点、水平重压、人物作为垂直承重构件
色彩：混凝土灰、深蓝、黑、骨白、一处褪红
避免：反乌托邦废墟、英雄姿态、混凝土毛孔、多个花盆
```

## TECH 变量

```text
标题：系统的浪漫
判断：你看建筑，先看它怎么运行 / 结构敢露出来，升级路线也得留出来
关键词：系统 / 装配 / 可升级
谱系：高技派 × 结构表现 × 环境技术
人物：三角脸、兴奋眉眼、手托五层以内爆炸结构模型、另一手调节节点
建筑：香港汇丰式外露桁架、斜撑、悬挂楼板和中庭空隙
构图：斜撑包围人物，结构模型成为胸前焦点
色彩：银灰、青蓝、黑、骨白、一个荧光绿节点
避免：全息 UI、代码、赛博朋克、螺栓海、硬帽职业刻板印象
```

## FLOW 变量

```text
标题：直线失效以后
判断：你不接受空间原地站好 / 地面、墙和屋顶最好一起起跑
关键词：速度 / 连续 / 越界
谱系：解构主义 × 新未来主义 × 流动空间
人物：楔形脸、成熟狂喜、斜向迈步、一手卷图、一手画非发光轨迹
建筑：盖达尔中心式连续白壳和一个深色切口
构图：从左下到右上的强对角线，人物与壳体同时向前
色彩：骨白、黑、深紫、亮橙、一处电蓝
避免：魔法光带、粒子、雾、超级英雄、不可读倾斜文字
```

## ORNA 变量

```text
标题：万物都想上场
判断：你相信日常值得认真演一场 / 结构、色彩和故事，都该有自己的戏份
关键词：戏剧 / 手工 / 想象
谱系：加泰罗尼亚现代主义 × 新艺术 × 总体艺术
人物：宽颧脸、半鞠躬、掌上小型陶瓷龙、服装只留一处碎瓷纹样
建筑：巴特罗之家式骨状阳台、曲窗、少量龙鳞屋顶
构图：曲面从两侧包围人物，中间仍留清晰呼吸区
色彩：珊瑚红、孔雀蓝、金黄、骨白、近黑
避免：儿童海报、狂欢节、活龙、密集马赛克、彩虹过载
```
