V2 通过本轮概念视觉验收，建议替代 V1 成为后续八人格扩展的当前角色基准

## 视觉检查

### 女性角色分布

- FLOW：通过。角色依然是全组速度感最强的一张，女性身份没有削弱动作和空间攻击性
- HAND：通过。角色被读成稳定、有经验的女性建造者，温和来自抱持材料和视线方向，而不是柔弱化处理
- 两位女性分别占据动态设计与材料实践位置，没有把女性集中到自然或装饰人格

### 面部抽象度

- ROOT：通过，抽象程度最高。五官被压缩成符号化几何面，仍能通过抬头方向读出安静感
- MASS：通过。眉骨、下颌和高领共同表达性格，面部不再像写实肖像
- TECH：通过。删除露齿笑后，注意力回到手、模型和系统
- FLOW：通过。短发、眼镜和大切面建立识别，未使用妆容符号
- ORNA：通过。戏剧性由服装、手势和陶瓷龙承担，脸部退回为抽象原型
- HAND：通过。面部和发型均由大块切面构成，材料仍是画面主叙事

### 家族感

- GRID 与 VOID 继续作为品牌锚点
- V2 的人物面部明暗边界更硬，五官信息减少，八张并排时不再出现“六张肖像插画加两张建筑人物”的割裂感
- 角色姿态、道具和建筑母题仍足以区分人格，没有因抽象而变成同一个人

## 已知观察点

- ROOT 的五官最简，正式资产精修时可以在不增加具象度的前提下微调眼部方向，但当前手机尺寸下不影响理解
- FLOW 的几何眼镜与 GRID 形成轻微呼应；它目前能帮助识别女性角色和速度方向，暂不视为重复问题
- 当前仍是概念资产，尚未接入正式结果页
