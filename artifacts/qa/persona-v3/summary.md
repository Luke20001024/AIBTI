# AIBTI V3 人格图生成与视觉验收

日期：2026-08-26

状态：八张源图、1200 × 1000 WebP、结果页首屏与 1080 × 1350 分享卡均完成；本地实装与 GitHub Pages 公网冒烟通过。

## 本轮解决的问题

V2 虽写入“低多边形”与“非照片”约束，但实际提示同时强调真实材料、近景建筑、自然光、建筑可识别和成人写实比例，造成模型把人物与建筑推向半写实建筑杂志插画。仓库此前也没有保存逐图提示词、统一负面约束、参考图优先级或可重复的后置美术门。

V3 将风格控制改为：

- 项目自有旧版 GRID 作为成人卡通与切纸角色锚点
- 用户提供的人格角色集合只作为抽象层级、少细节和角色家族一致性参考，不复制具体人物、版式或商业识别
- 各人格旧图只提供动作、道具和建筑叙事，不决定渲染风格
- 每张重复同一段二维风格母提示词，不再单独依赖“low-poly”一词
- 建筑只保留 4–8 个大轮廓面，禁止 PBR、真实反射、逐砖、逐叶、逐螺栓和摄影纹理
- 同一绘画语法不等于同一张脸；八张使用独立脸型、眉眼节奏、年龄感和表情，不以群体刻板符号制造差异
- 先生成 GRID／ROOT／FLOW 三个边界，再扩展其他五张；不通过只返修单张

完整母提示词、八人格变量、面部差异矩阵和硬性验收规则见 `docs/design/v3/persona-image-direction.md`；逐图来源、输出与评分见 `docs/design/v3/generation-manifest.json`。
